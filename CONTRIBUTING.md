# Contributing

Thanks for your interest in improving **react-native-dynamic-search-bar**! 🎉

## Development setup

This is a TypeScript React Native component library built with
[`react-native-builder-bob`](https://github.com/callstack/react-native-builder-bob).

```bash
git clone https://github.com/kuraydev/react-native-dynamic-search-bar.git
cd react-native-dynamic-search-bar
npm install --legacy-peer-deps
```

The library source lives in [`src/`](./src). The compiled output (`lib/`) is
generated by `npm run build` and is **not** committed.

## Scripts

| Script              | Description                                          |
| ------------------- | ---------------------------------------------------- |
| `npm run typecheck` | Type-check the source with `tsc --noEmit`            |
| `npm run lint`      | Lint with ESLint (flat config, `eslint.config.js`)   |
| `npm test`          | Run the Jest + React Native Testing Library suite    |
| `npm run build`     | Build CommonJS, ES Module and TypeScript definitions |
| `npm run format`    | Format the source with Prettier                      |

Please make sure `typecheck`, `lint`, `test` and `build` all pass before
opening a pull request — CI runs the same steps on a Node 18/20/22 matrix.

## Commit messages

This repo follows [Conventional Commits](https://www.conventionalcommits.org/).
Use prefixes such as `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`.

## Backwards compatibility

This is a widely-installed published library. **Do not** change public prop
names or their default values, or remove the default export, without flagging
the change as breaking and proposing a major version bump.

## Reporting issues

Open an issue with a minimal reproduction (an Expo Snack or repo link is ideal)
and the environment details requested in the bug template.
